# اتوبنز وحدت — نسخه نمایشی اندروید ۰.۲

نمایش اولیه صدور بارنامه، دریافت بار و گزارش مالی. زبان رابط فارسی و تاریخ‌ها جلالی هستند.

## تغییرات نسخه ۰.۲
- مبدأ ثابت «تهران» برای نسخه نمایشی
- مقصدهای قابل تعریف در «تنظیمات»؛ مقصد اولیه «قائم‌شهر»
- وقتی فقط یک مقصد موجود است، بدون نمایش فهرست، خودکار انتخاب می‌شود
- وقتی چند مقصد موجود است، انتخاب از فهرست بازشونده
- پیش‌کرایه + پس‌کرایه + انبارداری + سایر هزینه‌ها = جمع کل خودکار
- جداکننده سه‌رقمی هنگام ورود مبلغ به تومان
- نمایش جزییات مالی روی بارنامه و انتقال مبالغ جدید با QR نسخه ۲
- خواندن QR نسخه ۱ قبلی (برای سازگاری)
- بانک SQLite نسخه ۲ با مهاجرت و حفظ بارنامه‌های قبلی
- حذف نوشته‌های تبلیغی آفلاین و خلاصه اضافی صفحه اصلی
- رفع تداخل سربرگ با نوار وضعیت اندروید
- نمایش گزارش بر اساس داده‌های واقعی همان دستگاه

## ساخت APK
GitHub Actions -> Android demo APK -> artifact `vahdat-android-demo-apk`.

## آزمایش
گوشی تهران: «صدور بارنامه»، انتخاب مقصد، مبلغ‌ها، تولید QR. گوشی مقصد: «دریافت بار»، اسکن QR و تایید دریافت؛ سپس ثبت تحویل/وصول. هیچ اینترنتی برای این عملیات لازم نیست.

## محدودیت مهم آزمایشی
QR کدگذاری و فشرده شده اما رمزگذاری و امضای دیجیتال نشده است. از اطلاعات واقعی یا محرمانه مشتریان برای تست استفاده نکنید. اطلاعات در هر دستگاه جداگانه ذخیره می‌شود و بین گوشی‌ها همگام‌سازی خودکار وجود ندارد.

Kotlin / Jetpack Compose / SQLite / ZXing.
