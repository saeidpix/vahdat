# اتوبنز وحدت — نسخه صرفاً آزمایشی قائم‌شهر (Windows 7)

این نسخه برای **حداکثر ۳۰ بارنامه آزمایشی** و یک کامپیوتر Windows 7 با رم ۴ گیگ ساخته می‌شود. نسخه اصلی شرکت و سرور Windows Server 2019 را تغییر نمی‌دهد.

## قبل از نصب
- روی کامپیوتر آزمایشی قائم‌شهر نصب کنید؛ **نه روی سرور فروش بلیت**.
- فقط Windows 7 Service Pack 1، نسخه ۳۲ یا ۶۴ بیتی. نصب واقعی روی ویندوز ۷ هنوز باید تأیید شود؛ GitHub Actions روی Windows Server 2022 آزمایش می‌کند، نه Win7.
- برای رابط کاربری از مرورگر سازگار با رایانه استفاده کنید. Internet Explorer برای رابط برنامه قابل اعتماد نیست.
- ویندوز ۷ پشتیبانی امنیتی ندارد: فقط داده **آزمایشی و غیرحساس** وارد کنید. این نسخه سرویس را فقط به localhost متصل می‌کند و پورت شبکه داخلی باز نمی‌کند.

## نصب
1. خروجی GitHub Actions با نام `Vahdat-Win7-Qaemshahr-TEST-Setup` را دانلود و ZIP را استخراج کنید.
2. `Vahdat-Setup-Win7-Qaemshahr-PILOT-v1.5.7.exe` را نصب کنید.
3. برنامه را اجرا کنید. اگر مرورگر خودکار باز نشد، `http://127.0.0.1:8877` را در همان کامپیوتر باز کنید.
4. مدیر اولیه آزمایشی را ثبت کنید.
5. برگه تنظیمات باید مبدأ **قائم‌شهر** و مقصد **تهران** را نشان دهد.

## پوشه داده آزمایشی
`C:\ProgramData\VahdatPilotQaemshahr\`

دیتابیس مستقل: `vahdat.sqlite3`. کلیدهای Flask و فایل `sync-config.json` هم در همین پوشه قرار می‌گیرند. نصب یا حذف برنامه **نباید** داده‌های مرکز یا SQL Server فروش بلیت را تغییر دهد.

## فعال کردن تبادل آزمایشی با تهران
مرکز Laravel روی `https://autobenzvahdat.ir` نصب شده ولی اتصال شعبه‌ها و کلیدهای عملیاتی هنوز باید تنظیم شوند.

- مدیر کل در `https://autobenzvahdat.ir/admin/vahdat/branches`، شعبه **قائم‌شهر** و شعبه **تهران** را فعال می‌کند و برای هر یک کلید مستقل صادر می‌کند.
- روی کامپیوتر قائم‌شهر، پس از نصب، فایل زیر ساخته می‌شود (کلید واقعی را در چت نفرستید):
```json
{
  "enabled": true,
  "branch_id": "qaemshahr",
  "branch_name": "قائم‌شهر",
  "hub_url": "https://autobenzvahdat.ir",
  "token": "REAL_QAEMSHAHR_BRANCH_TOKEN"
}
```
این JSON را با کلید واقعی در `C:\ProgramData\VahdatPilotQaemshahr\sync-config.json` (UTF-8) ذخیره کنید و برنامه را بسته و مجدداً باز کنید.

- سیستم تهران هم باید **جداگانه** با شناسه `tehran` و کلید خودش به مرکز وصل شود. اگر تهران هنوز متصل نشده است، انتقال انتهابه‌انتها اتفاق نمی‌افتد.
- فقط مبدأ قائم‌شهر به مقصد تهران مجاز است. برای آزمایش مسیر تهران → قائم‌شهر، از نسخه محلی تهران بارنامه آزمایشی صادر کنید.
- پس از ثبت هر بارنامه تستی، وضعیت صف ارسال، آخرین اتصال، دریافت مقصد و تحویل را بررسی کنید.
- تا تأیید تست رفت و برگشت **هیچ بار واقعی مشتری** ثبت نکنید.

## شناسه و شماره بارنامه
شماره محلی در دیتابیس تست از **۱** شروع می‌شود و تا **۳۰** اجازه صدور دارد. شناسه یکتای بارنامه از پیشوند `VH-PILOT-` استفاده می‌کند تا در مرکز از شناسه‌های عملیاتی قابل تشخیص باشد.

## بعد از پایان آزمایش
1. گزارش تست، سوابق، بازخورد چاپ و بارکدخوان را نگه دارید.
2. اتصال آزمایشی را غیرفعال و از داده‌های تست بکاپ بگیرید.
3. شناسه‌های `VH-PILOT-` و رویدادهای تست در مرکز باید به روش کنترل‌شده **آرشیو/جداسازی** شوند؛ نباید دیتابیس رزرو بلیت یا سایر داده‌های مرکز را پاک کرد.
4. روی Windows Server 2019 نسخه **عملیاتی جدید با دیتابیس تازه** نصب می‌شود و شماره بارنامه از **۱** آغاز می‌شود. **دیتابیس آزمایشی ویندوز ۷ را منتقل نکنید.**
5. پس از تست چاپ، قطع اینترنت و ارتباط واقعی، نسخه کاربران شعب ساخته می‌شود.

## محدودیت‌ها
- Python 3.8 و نسخه‌های قدیمی‌تر بعضی کتابخانه‌ها برای سازگاری با ویندوز ۷ استفاده شده‌اند؛ این شاخه مناسب تولید نهایی نیست.
- ساخت موفق در GitHub **اثبات اجرای موفق روی Windows 7 نیست**. اولین نصب روی دستگاه واقعی لازم است.
- این نسخه پرتابل نیست و در شبکه محلی سرویس عمومی باز نمی‌کند؛ صرفاً UI محلی همراه با همگام‌سازی خروجی HTTPS است.
