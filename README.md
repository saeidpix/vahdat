# اتوبنز وحدت | Vahdat Android Demo

نسخه نمایشی اندروید شرکت اتوبنز وحدت، کاملاً آفلاین و بدون نیاز به سرور یا VPN.

## امکانات
- صدور بارنامه با کمترین فیلد و بدون بررسی سختگیرانه موبایل.
- تولید QR حاوی اطلاعات بارنامه و اسکن آن در گوشی دوم.
- ثبت دریافت و تحویل کالا با تاریخ و ساعت خودکار تا ثانیه.
- نمایش تاریخ‌های شمسی و مبالغ به تومان.
- گزارش مالی ساده برای هر گوشی و جلوگیری از ثبت تکراری شماره بارنامه.
- پایگاه داده SQLite داخلی؛ هر گوشی مستقل است.

## ساخت
Android Studio با Java 17 و Android SDK 35: پروژه را باز و task assembleDebug را اجرا کنید.

در GitHub Actions، workflow به نام Android demo APK پس از هر push فایل vahdat-android-demo-apk را به عنوان artifact ارائه می‌دهد (در صورت موفقیت build).

## آزمون با دو گوشی
1. روی هر گوشی تنظیمات شعبه را باز کرده و نام متفاوتی وارد کنید.
2. گوشی مبدأ بارنامه صادر کند و QR را نمایش دهد.
3. گوشی مقصد دکمه «دریافت بار» را بزند و QR را اسکن کند.
4. دریافت و سپس تحویل کالا و وصول پس‌کرایه ثبت شود.
5. گزارش مالی گوشی مقصد نمایش داده شود.

## هشدار
QR در این نسخه فقط فشرده است، نه رمزگذاری یا امضای دیجیتال. برای آزمایش از نام و اطلاعات ساختگی استفاده شود. وضعیت تحویل به گوشی مبدأ برنمی‌گردد؛ همگام‌سازی در نسخه بعدی طراحی می‌شود. گزارش نسخه اول جایگزین سامانه عملیاتی مالی نیست.

Tech: Kotlin, Jetpack Compose, SQLiteOpenHelper, ZXing, Android 8+.
