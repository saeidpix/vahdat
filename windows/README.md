# اتوبنز وحدت — نسخه ویندوز ۱.۱.۰

فایل نصبی Windows x64 برای **Windows 10/11 و Windows Server 2019** ساخته می‌شود. نسخه تحت وب محلی است: روی یک ویندوز نصب می‌شود و در مرورگر همان سیستم باز می‌شود؛ کلاینت‌های همان LAN بدون نصب اضافه به آن وصل می‌شوند.

## نصب
۱. فایل Vahdat-Setup-Windows-v1.1.0.exe را روی کامپیوتر/سرور شعبه نصب کنید.
۲. از منوی Start برنامه «اتوبنز وحدت» را باز کنید. مرورگر http://127.0.0.1:8765 را نشان می‌دهد.
۳. کلاینت‌های LAN با http://IP-سرور:8765 وصل می‌شوند. رایانه میزبان و برنامه باید در حال اجرا بمانند.
۴. با اسکنر دوبعدی USB که در حالت کیبورد HID تنظیم است، در صفحه دریافت بار QR را اسکن کنید. معمولاً اسکنر باید پس از داده کلید Enter بفرستد.

## امکانات
- مبدأ تهران، مقصد اولیه قائم‌شهر؛ مقصدها در تنظیمات قابل افزودن و حذف
- صدور بارنامه بدون بررسی سخت‌گیرانه موبایل
- مبلغ‌های مستقل پیش‌کرایه، پس‌کرایه، انبارداری و سایر هزینه‌ها؛ محاسبه خودکار جمع کل و جداکننده هزارگان
- QR سازگار با برنامه Android نسخه ۰.۲ و خواندن QR نسخه ۰.۱
- دریافت، تحویل، وصول، گزارش مالی با تاریخ‌های شمسی و دقت ثانیه
- SQLite در مسیر `%ProgramData%\Vahdat\vahdat.sqlite3` روی سرور، ثبت مشترک کلاینت‌ها
- بکاپ‌گیری قابل دانلود از تنظیمات

## محدودیت‌ها
فقط نسخه نمایشی است. **فاقد حساب کاربری، HTTPS و امضای رمزنگاری‌شده QR** است. هر کسی در همان LAN به پورت 8765 دسترسی داشته باشد امکان مشاهده و تغییر داده‌ها را دارد. برای عملیات واقعی یا اطلاعات حساس مشتری استفاده نشود. پیش از استقرار عملیاتی باید امنیت، لاگ پیشرفته، بکاپ منظم و اجرای سرویس ویندوز اضافه شود.

این نسخه از Flask / Waitress / SQLite و PyInstaller استفاده می‌کند. روند تولید Setup در GitHub Actions و Inno Setup قرار دارد.

## اصلاح نسخه ۰.۱.۱
خطای پرانتز در کد جاوااسکریپت فرم صدور رفع شد؛ این خطا قبلاً باعث می‌شد صفحه خالی و همه دکمه‌ها غیرفعال شوند. آزمون خودکار نحو جاوااسکریپت و شش صفحه اصلی به فرایند ساخت افزوده شد. پیش از نصب نسخه جدید، برنامه VahdatServer.exe قبلی را در Task Manager ببندید و سپس فایل Setup جدید را اجرا کنید؛ دیتابیس در ProgramData جدا از فایل برنامه باقی می‌ماند.


## نسخه ۱.۰.۰
رابط شش صفحه با عناصر واقعی HTML/CSS/JS، آیکون‌های SVG و تصویر مستقل سمند بازطراحی شد. متن‌های کمکی کارت‌ها حذف شدند. مبلغ‌ها و گزارش‌ها از API و SQLite واقعی می‌آیند.

شماره نمایشی بارنامه‌ها عددی و پیوسته از ۱ است. شناسه یکتای داخلی VH و قالب VHD1 بدون تغییر باقی می‌مانند تا QRهای اندروید قدیم قابل خواندن بمانند. شماره نمایشی در یک تراکنش SQLite با قفل نوشتن تخصیص می‌یابد. سوابق قدیم به ترتیب تاریخ شماره می‌گیرند؛ شناسه، مبلغ‌ها، تاریخ‌ها و وضعیت آن‌ها عوض نمی‌شود. هر بارنامه دریافتی نیز در بانک همین سرور یک شماره محلی می‌گیرد.

در اولین اجرای ارتقا، پیش از افزودن ستون شماره، SQLite Online Backup از بانک موجود (با داده‌های WAL) در `%ProgramData%\Vahdat\backups` می‌سازد. مسیر اصلی بانک و AppId نصب ثابت هستند. نصب و حذف برنامه، بانک اطلاعاتی را حذف نمی‌کنند. نسخه قبلی برنامه را پیش از نصب ببندید.

آزمون‌ها: `node windows/test_ui.cjs`، `python -m unittest discover -s windows -p test_*.py -v` و `python windows/browser_test.py`. آزمون مرورگر از HTTP و بانک جداگانه استفاده می‌کند و صدور، مبالغ، QR، دریافت، تحویل، گزارش، مقصدها، بکاپ و چهار اندازه نمایش را می‌سنجد. Actions پس از آزمون‌ها فایل x64 را می‌سازد و اجرای فایل بسته‌بندی‌شده و موجودبودن تصاویر را بررسی می‌کند.

تصویر هدر با ابزار داخلی تولید تصویر ساخته شده و در `windows/assets/samand.png` نگهداری می‌شود؛ سایر عناصر رابط کد واقعی هستند. دستور تصویر: "Photorealistic yellow Iran Khodro Samand taxi, classic Samand LX, front three-quarter view facing left, entire vehicle, transparent background, studio lighting, no text or watermark."


## طراحی نسخه ۱.۱.۰
فونت متغیر وزیرمتن با مجوز OFL به‌صورت آفلاین بسته‌بندی می‌شود. آیکون‌ها یک مجموعه SVG رنگی مشترک با گرادیان و لایه‌های واقعی هستند. خانه چهار کارت در دو ردیف دارد، دکمه صدور داخل کارت هزینه‌ها قرار گرفته، گزارش مالی پنج کارت متوازن دارد، و تنظیمات مقصدها و بکاپ در دو ستون جمع‌وجور است. فرم‌ها، جدول، دریافت QR و جزئیات/چاپ هم از همان سبک استفاده می‌کنند؛ متن کمکی جدیدی اضافه نشده است.

نسخه ۱.۱.۰ هیچ تغییر ساختاری در SQLite یا قالب QR ایجاد نمی‌کند. شماره‌های موجود و اطلاعات قبلی حفظ می‌شوند. آزمون مرورگر شش اندازه نمایش از ۳۹۰ تا ۱۹۲۰ پیکسل، بارگذاری فونت و تصاویر و آیکون‌ها، جای دکمه صدور، هم‌ردیف‌بودن پنج کارت گزارش و کارکرد واقعی API را بررسی می‌کند.
